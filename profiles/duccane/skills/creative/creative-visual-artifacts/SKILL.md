# Creative Visual Artifacts

Use this umbrella for creative visual output: one-off HTML artifacts, landing pages, design-system-inspired mockups, architecture diagrams, infographics, Excalidraw-style sketches, p5.js demos, Manim animations, ASCII art/video, ComfyUI, and TouchDesigner.

## Choose the Medium

| Desired output | Use |
|---|---|
| Fast UI/landing/deck prototype | HTML/CSS artifact |
| System/cloud/infra diagram | SVG/HTML architecture diagram |
| Hand-drawn flow or map | Excalidraw JSON |
| Data/story infographic | infographic layout/style references |
| Generative browser art | p5.js |
| Math/algorithm animation | Manim |
| Image/video/audio generation graph | ComfyUI |
| Realtime interactive visuals | TouchDesigner |
| Text-mode effect | ASCII art/video |

## Common Workflow

1. Define audience, aspect ratio/canvas, output format, style, and constraints.
2. Build a complete artifact, not a vague prompt, when local rendering is possible.
3. Save the output path and any source/template files.
4. Validate by opening/rendering/screenshotting where possible.
5. Iterate based on visual defects, not just code lint.

## HTML, Mockups, and Design Systems

- For one-off browser artifacts, produce a self-contained HTML/CSS/JS file.
- For brand-inspired work, use references/templates as style cues, not trademark-copying.
- For diagrams, prioritize semantic grouping, contrast, readable labels, and exportable SVG/HTML.

## Motion and Interactive Media

- For p5.js/Manim/ASCII video, verify render commands and artifact paths.
- Keep frame rate, resolution, and duration explicit.
- For TouchDesigner/ComfyUI, preserve workflow/config files and dependency notes.

## Rules

- Never claim an image/video/diagram was rendered unless a tool produced or opened it.
- Keep detailed style/layout catalogs in references/templates; use this umbrella for discovery.
